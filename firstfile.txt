git stash apply
What it does: Applies your stashed changes back onto your project files, but keeps a copy in the stash vault
 git stash list
What it does: Shows a list of all stashes currently stored in your vault (e.g., stash@{0}, stash@{1})
git stash drop / git stash clear
What it does: git stash drop removes the most recent stash from the vault. git stash clear wipes out all stashes permanently.
git stash list --date=local  List your stashes with dates (git stash list)
Run this command to see all your stashes along with their exact creation dates:
git stash show stash@{1}  See which files are inside that stash
To check the list of files stored inside that specific stash (stash@{1}), run:
Restore ONLY that specific file
To bring back only your desired file from that stash (without touching any other files in that stash or wiping out your current work), run:
git checkout stash@{1} -- path/to/your/filename.txt
(Replace stash@{1} with your stash number and path/to/your/filename.txt with the exact file name/path).
